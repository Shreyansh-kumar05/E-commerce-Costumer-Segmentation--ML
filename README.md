E-Commerce Customer Segmentation using Machine Learning

📌 About the Project

This project focuses on analyzing and segmenting e-commerce customers based on their purchasing behavior using RFM (Recency, Frequency, Monetary) analysis.

Unsupervised Machine Learning algorithms, K-Means and DBSCAN, are applied to identify different customer groups. PCA is used for dimensionality reduction, while t-SNE helps visualize customer segments in 2D space.

🎯 Objectives

- Analyze customer purchasing behavior using RFM analysis.
- Identify customer segments using K-Means clustering.
- Apply DBSCAN for density-based clustering.
- Perform dimensionality reduction using PCA.
- Visualize customer segments using t-SNE.
- Develop customer personas and suggest marketing strategies.

📂 Dataset

The project uses an online retail transactional dataset.

- Dataset Source: https://www.kaggle.com/datasets/lakshmi25npathi/online-retail-dataset?utm_source=chatgpt.com
- Format: CSV
